# Navigation area helper in UserDashboard to help navigate through current actively displayed tables

- The number of tables displayed in the user dashboard might be too many that the user could scroll alot before getting to the desired table.
- I was thinking that mayble we could add a sticky navigation area helper (rounded section with a border - color choice you can decide based on your recommendation)
- This navigation section lists the current displayed tables, and clicking on one navigation button scrolls instantly to that table area (no smooth animation).
